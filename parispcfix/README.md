# PARISPCFIX Remote Support — integrated engine branch

Основа: RustDesk 1.5.3, исходная ревизия `3e953e886a874956d8351d6c25e340ea82dd2343`. Это изменения исходников самого приложения, а не запуск установленного RustDesk из сторонней панели.

## Внесено

- Две отдельные функции сборки Cargo: `parispcfix-client` и `parispcfix-admin`. Одновременное включение запрещено компилятором.
- Собственные имена приложения и профили: `PARISPCFIX-CLIENT` / `PARISPCFIX-ADMIN`.
- Клиент использует штатный входящий режим, специалист — исходящий. Это режимы приложения, а не серверная система аккаунтов.
- Пять языков в выборе: русский, румынский, украинский, английский, французский. Используются переводы движка; незаполненные переводы могут иметь английский резервный текст.
- Фирменный логотип в интерфейсе, SVG-значок, фон ночного Парижа и бирюзовый акцент. Логотипы и указание Powered by убраны из основного интерфейса фирменной сборки. Исходные уведомления о лицензиях и авторских правах сохранены.
- Сеансы, файловый менеджер, мониторы, звук, чат, запись и запросы повышения прав остаются внутри собираемого приложения.
- Windows-сборка включает флаг оформления Dart и выпускает отдельные самораспаковывающиеся `PARISPCFIX-CLIENT-...-install.exe` и `PARISPCFIX-ADMIN-...-install.exe` со штатным встроенным установщиком движка.
- Добавлен отдельный GitHub Actions workflow с генерацией моста в CI и двумя Windows-сборками. Он не публикует релиз, не меняет доступ к репозиторию и сам пока не запускался.

Без функций Cargo и Dart-флага оформление и основной путь исходного приложения сохраняются. Изменения протокола, отключение проверки подписи конфигурации, обход UAC и скрытие уведомлений об активном доступе не вносились.

## Текущее состояние

**Готовые EXE с интегрированным движком ещё не собраны.** Проверка компиляции в текущей среде остановилась на отсутствующих Git-зависимостях Cargo. Доступ этой среды к GitHub по DNS не работает; сеть в пользовательском PowerShell работает.

Отсутствуют Flutter SDK, vcpkg с нативными библиотеками и генерируемые файлы Flutter/Rust bridge. Visual Studio Build Tools и Rust уже обнаружены. `Prepare-Windows.ps1` умеет загрузить Flutter 3.24.5 с проверкой SHA-256 и vcpkg фиксированной ревизии в папку проекта. Для этого в обычном PowerShell:

```powershell
Set-Location C:\ParisPcFix-Audit\remote-support\engine-source
& .\parispcfix\Prepare-Windows.ps1 -DownloadTools
```

Скрипт подготавливает инструменты, но не собирает приложение. По правилам репозитория генератор моста локально не запускается. Готовый workflow `.github/workflows/parispcfix-windows.yml` генерирует мост на Linux в CI, а затем собирает обе Windows-редакции на Windows runners. Для запуска нужен свой репозиторий с этими изменениями и доступ к Actions; в исходный репозиторий RustDesk ничего не отправлялось.

Автозагрузка, служба, постоянный доступ, сохранение паролей и запись нуждаются в проверке именно после сборки. Заметки и PDF-отчёт из прежних экспериментальных панелей пока в этот интерфейс не перенесены. Подписанных установщиков macOS/Linux эта ветка пока не выпускает.

## Область изменений

`.gitignore`: исключает локальные инструменты и выходные файлы сборки, но сохраняет фирменные PNG/SVG-ресурсы в Git.
`Cargo.toml`, `src/lib.rs`: функции сборки и подключение отдельного модуля бренда.
`src/core_main.rs`, `src/flutter_ffi.rs`: ранняя установка имени и режима до загрузки конфигурации.
`src/ui_interface.rs`: ограничение списка языков только в фирменной сборке.
`flutter/lib/common.dart`: фирменный логотип, значок и цвет; исходный путь остаётся при выключенном флаге.
`desktop_home_page.dart`: фон и полупрозрачные панели домашней страницы.
`desktop_tab_page.dart`: доступ к настройкам клиента, чтобы можно было выбрать язык и управлять разрешениями.
`tabbar_widget.dart`: название фирменного приложения в заголовке.
`flutter/windows/CMakeLists.txt`, `Runner.rc`: метаданные Windows только для фирменной сборки.
`build.py`: передача функций Cargo и флага Dart, имена реальных EXE и установщиков.
`libs/portable/build.rs`: метаданные самораспаковывающегося установщика.
`libs/portable/src/ui.rs`: фирменная надпись при распаковке.
`src/tray.rs`: фирменный значок в системном трее. Проверки доступа и команды управления службой не менялись.

Подмодуль `libs/hbb_common` не менялся. Лицензия исходной основы — AGPL-3.0; файл `LICENCE` включается в артефакты сборки.
